# DBA Hypotheekdashboard

Intern hypotheekdossieroverzicht voor DBA Advies.

## Starten

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — de app redirect naar `/in-behandeling`.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- lucide-react (iconen)

Deze eerste versie bevat alleen de visuele basis met mockdata. Geen database, authenticatie of CRUD.
